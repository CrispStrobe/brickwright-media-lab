# Corsham xKIM

`./fetch.sh` retrieves the exact [GPLv3 upstream source](https://github.com/CorshamTech/xKIM/tree/0ce44974504514563e86cdf84ac8a9848b8bcdb5).
See the upstream `make.bat` for its assembler invocation. The extension ROM
can be mapped read-only at $E000 with a programmable memory card. The kit
is source-only. This entry does not claim that xKIM's FAT file commands run
over the simulator's Corsham sector interface.
