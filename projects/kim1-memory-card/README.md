# KIM-1 programmable memory card

Run `./fetch.sh` to retrieve Eduardo Casino's [v1.1.0 source](https://github.com/eduardocasino/kim-1-programmable-memory-card/tree/e33587e356df8c069471516b70ab9b4ed4f571aa).
The source includes the `memcfg` utility, the physical Pico firmware, and
the hardware documentation. See the [per-directory licenses](https://github.com/eduardocasino/kim-1-programmable-memory-card/blob/e33587e356df8c069471516b70ab9b4ed4f571aa/LICENSE.md).
A whole-map `memcfg` raw export can be loaded and saved from the KIM-1
Circuits panel. For an original example map, see [KIM-1 expansion demos](../kim1-expansion-demos).
