# Adafruit CAD Parts original collection

The `original/` directory is an unmodified file-for-file mirror of
[Adafruit_CAD_Parts](https://github.com/adafruit/Adafruit_CAD_Parts) at commit
`9f2a89f3d5c3491886d58cb7fe83385417563cf4`, including its original README,
MIT license, CAD files, images and other files. Its own root [LICENSE](original/LICENSE)
applies; the Media Lab repository's top-level GPL does not replace that notice.
Copyright (c) 2016 Adafruit Industries.

`files.json` records each upstream path, byte count and SHA-256 digest. File
formats, units and orientation have not been independently established or
screened; a filename is not evidence of printability, mechanical accuracy or
collision safety. No models have been modified or converted. The upstream tree
contains no additional files named license, copyright, notice, copying or readme;
this filename search is not a review of every embedded binary notice.
