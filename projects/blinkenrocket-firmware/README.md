# Blinkenrocket firmware (ATtiny88)

Upstream: <https://github.com/CrispStrobe/blinkenrocket-firmware>
(GPL, fork of derf/blinkenrocket) — branch `minigame-as` carries the
788AS display support and the minigame. Build with avr-gcc per the
upstream README; flash the hex onto the app's attiny88 machine.
Verified under emulation: boot glyph pixel-identical, RIGHT button
enters the game court.
