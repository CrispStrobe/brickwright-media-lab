# Steamboat Willie on the Ben Eater 6502

Upstream: <https://github.com/NormalLuser/Ben-Eater-Bad-Apple> (GPL-3.0)
— same author, same rig as Bad Apple; the film is Walt Disney's 1928
Steamboat Willie, US public domain since 2024, so the ENCODED DATA is
GPL over a public-domain source: the cleanest demo of the set. Uses
the author's Steamboat decoder (see upstream `SteamboatWillieDecode.asm`).
Run status: data verified fetchable; decoder pairing not yet proven on
the simulated machine (the Bad Apple player/format pairing is).
